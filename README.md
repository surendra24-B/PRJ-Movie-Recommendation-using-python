# 🎬 Movie Recommendation System using Python

An end-to-end data analysis and machine learning project that builds a recommendation engine to suggest movies based on user preferences and movie similarities. 

---

## 🚀 Project Overview
This project focuses on exploring movie datasets, analyzing user viewing patterns, and implementing a recommendation system. The goal was to improve my data analysis, feature engineering, and Python programming skills while solving a real-world predictive modeling problem.

## 🛠️ Tech Stack & Libraries
- **Language:** Python 3
- **Data Analysis & Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Development Environment:** Jupyter Notebook (`.ipynb`)

## 📊 Key Insights & Analysis Workflow
1. **Data Cleaning:** Handled missing values, parsed genres, and formatted timestamps for consistent analysis.
2. **Exploratory Data Analysis (EDA):** 
   - Analyzed the distribution of movie ratings.
   - Identified top-rated movies and the most popular genres.
   - Discovered patterns in how different user segments rate specific movie types.
3. **Recommendation Strategy:** Developed an approach to compute similarity scores between movies to provide relevant alternative recommendations.

## 📂 Repository Structure
- `Movie Recommendation.ipynb`: The core Jupyter Notebook containing data preprocessing, visualization, and modeling.
- `Movie Recommendation.html`: An exported HTML version of the notebook for quick, interactive viewing in any browser.
- `README.md`: Project documentation.
